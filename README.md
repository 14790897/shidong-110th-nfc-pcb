# 市东中学110周年NFC纪念卡 PCB

上海市市东中学（上海市市东实验学校）110周年校庆 NFC 纪念卡 PCB 设计。



https://github.com/user-attachments/assets/d230654b-1e45-41c2-8e9a-1083c650a9f8


## 项目简介

本项目为市东中学 110 周年校庆设计的 NFC 纪念卡电路板。使用立创 EDA 专业版（EasyEDA Pro）进行设计。

| `沉金版市东中学周年庆纪念NFC卡.mp4` | 沉金版实物展示视频 |

## PCB 下单

在立创 EDA 专业版中打开工程文件，导出 Gerber 后即可打样，详见 [立创 EDA 专业版 PCB 下单指南](https://prodocs.lceda.cn/cn/pcb/order-order-pcb/index.html)。
